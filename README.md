# 2026 臺北白晝之夜個人行程

這是一份個人整理的 2026 臺北白晝之夜（Nuit Blanche Taipei）行程，不是官方網站。

## 開啟方式

用瀏覽器打開 GitHub Pages 網址：

https://ld666-tw.github.io/nuitblanche.taipei2026/

啟用後若暫時 404，等一兩分鐘再重新整理。本機預覽可直接打開倉庫根目錄的 `index.html`。

## Google 地圖

頁面裡的 Google 地圖 embed 必須透過 **HTTPS** 開啟才會顯示。請用上面的 Pages 網址；若以 `file://` 在本機直接開檔，地圖會是空白。也可以改點頁面上的「在 Google 地圖開啟」。
